# Update Notes: 2026-06-24 12:02:00 UTC

## Auto-Grant Prerequisite Permissions 
- Fixed the annoying "Validation Error: Cannot grant 'Edit File' without 'Update File'" and similar UI blocks when trying to submit bulk permissions.
- **Backend Fix**: Instead of throwing a validation error and aborting the save process if you enable a dependent permission without its prerequisite, `web_routes.py` now silently auto-grants the missing prerequisite (e.g. automatically granting 'Update File' if 'Edit File' is granted, or 'Run' if 'Update' is granted).
- **Frontend Fix**: Added `onchange` logic to the checkboxes in `permissions.html`. Now, whenever you check "Edit File", "Delete Folder", or "Update" (for scripts), the UI will automatically visually check the corresponding prerequisites ("Update File", "Create Folder", "Run"). This resolves the conflict before you even click submit!
